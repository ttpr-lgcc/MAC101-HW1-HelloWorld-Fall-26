# Assignment 1: Hello, World!

**Course:** Introduction to C++  
**Due Date:** 9/28/26  
**Points:** 10

## 🎯 Objective
The goal of this assignment is to ensure your C++ development environment is set up correctly and that you understand the basic structure of a C++ program. You will write a simple program that outputs a greeting to the console.

## 📝 Instructions

1. **Create your file:** Create a new C++ source file and name it `main.cpp`.
2. **Include the necessary library:** You will need to include the standard input/output stream library (`<iostream>`) at the top of your file to use the printing functions.
3. **Write the main function:** Define the `int main()` function. This is the entry point of every C++ program.
4. **Print the message:** Inside the main function, use `std::cout` to print the exact phrase: `Hello, World!`
5. **End the line:** Make sure to end the line with `std::endl` or `\n`.
6. **Return success:** End your main function by returning `0` to indicate that the program executed successfully.

## 💻 Expected Output
When you compile and run your program, the console output should look exactly like this:
```text
Hello, World!
```

## ✅ Rubric
* **File named correctly (`main.cpp`):** 2 pts
* **Correct `#include` directive:** 2 pts
* **Valid `main()` function structure:** 2 pts
* **Correct syntax and use of `std::cout`:** 2 pts
* **Exact output match ("Hello, World!"):** 2 pts
